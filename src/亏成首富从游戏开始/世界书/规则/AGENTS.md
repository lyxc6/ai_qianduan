# AGENTS.md - 亏成首富从游戏开始项目

## 项目概述
基于网络小说《亏成首富从游戏开始》的游戏/互动叙事系统。核心机制：玩家经营产业，亏损转化为个人财富，盈利转化比例低。

## 文件结构
- `亏成首富从游戏开始.txt` - 小说原文（参考素材）
- `*.yaml` - 游戏规则配置文件（主要工作对象）

## 关键YAML文件
| 文件 | 用途 |
|------|------|
| `核心规则.yaml` | 资金流转限制、产业/个人用途判定 |
| `亏本系统.yaml` | 系统机制、盈亏转换比例 |
| `反作弊规则.yaml` | 禁止玩家代替NPC行动/对话/决策 |
| `反恶意行径.yaml` | 防止滥用系统漏洞 |
| `月度结算-资金补充机制.yaml` | 资金补充计算、活跃度修正 |
| `人力资源逻辑.yaml` | NPC管理、薪资满意度 |
| `设定-性格指导.yaml` | 五维性格模型（g/p, i/e, t/f, r/c, m/n） |
| `通用叙事原则.yaml` | 叙事风格和呈现方式 |
| `叙事基调.yaml` | 整体叙事基调 |
| `跨国贸易与税率规则.yaml` | 贸易和税务系统 |
| `时间跳跃规则.yaml` | 时间推进机制 |

## 变量结构
- **产业列表**：记录公司信息（母公司/子公司/持股公司）
- **资产列表**：记录固定资产、无形资产等
- **产品列表**：记录具体产品线
- **核心角色**：记录NPC信息
- **经营系统**：记录盈亏转换比例、补充倍率等

## 开发约定
1. **YAML格式** - 所有规则使用YAML格式，保持缩进一致（2空格）
2. **中文注释** - 文件内使用中文注释说明设计意图
3. **规则联动** - 修改规则时检查`与其他系统的联动`部分，确保一致性
4. **叙事优先** - 系统提示通过叙事方式呈现，不直接显示为系统消息

## 常见任务
- **添加新规则**：参考现有YAML文件结构，添加到对应文件或创建新文件
- **修改判定逻辑**：更新`核心规则.yaml`中的判定流程
- **调整数值平衡**：修改`亏本系统.yaml`或`月度结算-资金补充机制.yaml`中的参数
- **添加NPC性格**：使用`设定-性格指导.yaml`中的五维模型格式

## 注意事项
- 玩家只能控制自己的行动，NPC反应由AI根据性格设定生成
- 资金补充不计入产业收入，只作为周转资金
- 小额灰色地带支出累积到一定程度再产生反馈
- 判定标准随产业规模调整：个体户阶段宽松，企业规模后严格
