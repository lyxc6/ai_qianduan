# 第一条消息：财富转换系统觉醒

2009年，汉东省京州市。

秋日的阳光透过大学宿舍那扇总是关不严的门，斜斜地照在裴谦的脸上。

"谦哥，快醒醒，上课要迟到了！今天是副院长的课，可是要点名啊！"

一个熟悉的、略带焦急的声音在耳边响起。

裴谦迷迷糊糊地睁开眼睛，看到一张大长脸几乎贴到了自己脸上。

"马洋？"

他下意识地叫出了这个名字，随即整个人都愣住了。

等等，我不是在做梦吧？

我记得我已经毕业好多年了啊，社畜生活那么多年，怎么突然回到大学宿舍了？

而且是这张大长脸...我记得马洋毕业之后就回老家发展去了，好久没联系了...

"快点啊谦哥，副院长真的要点名的！上次隔壁寝室的老张迟到，直接被记了旷课！"马洋催促道，催促完就转身急匆匆地走出了寝室。

房间里仅剩的两个室友也在收拾东西准备出门。

"快点啊谦哥，抓紧跑两步，还能赶上。否则点名的时候我们可不敢替你喊到啊，被副院长逮住那可就惨了。"

两个室友也匆忙出门了。

裴谦坐在床上，愣了好一会儿。

他使劲揉了揉眼睛，环顾四周。

六人间宿舍，上铺下铺，铁架子床，蓝白相间的被褥，门口那个永远关不严的小缝...

一切都那么熟悉，又那么陌生。

这是2009年，大一刚开学不久。

副院长的课，还点名...

等等，副院长的课？

裴谦突然想起来，副院长的课虽然嘴上说点名，但实际上从来没真的点过。

反倒是一个看起来一团和气的年轻男老师，从来不点名，期末突然点了一次，还计入了考试成绩。

"我不是想点名，就是想认识一下大家。"

那老师是这么说的。

想到这里，裴谦忍不住苦笑。

到现在他想起来，还有一种深深地被套路了的感觉。

"真是的..."裴谦自言自语道，"都已经过去这么多年了，还记得这么清楚..."

他正准备下床，突然眼前一花。

一片透明的光幕凭空出现在视野中，一行行金色的字迹不断显示出来。

【财富转换系统正在绑定宿主...】

【绑定成功。】

【宿主：裴谦】

【系统版本：v1.0】

【请宿主阅读本系统的使用须知。】

"什么情况？！"

裴谦吓了一跳，差点从床上摔下去。

但随即，他整个人都兴奋了起来。

穿越之后必有系统，这是金手指啊！

果然，网文诚不欺我！

裴谦深吸一口气，强迫自己冷静下来。

淡定，淡定。

穿越带系统，这是常规套路，没什么好大惊小怪的。

他开始认真观察光幕上的文字信息。

那是一个简洁的界面，分为几个部分：

【财富转换系统】

【盈余/亏损转化比：待定】

【系统资金：50000】

【个人财产：443】

这是基本信息栏。

在下方，有一个类似对话框的区域，专门用来显示"使用须知"。

【财富转换规则：】

【每隔一段时间，系统都将为宿主提供一定数量的系统资金，该资金仅可用于公司正常的商业活动，不可挥霍。】

【一段时间后将进行结算，相对于系统资金的盈余或亏损部分，将各自按照一定比例，转换为宿主可自由支配的个人财产。】

【特别注意：为激励宿主专注于工作，宿主不可以通过公司账户直接向自己发放薪酬。】

【下一步：查看详细规则】

"哦哦？这个系统，血赚啊！"

裴谦眼睛一亮。

"你给我提供资金，还给我分钱？良心系统！"

他瞬间理解了这个系统的功能。

虽然都叫"钱"，但"系统资金"和"个人财产"是两种完全不同的概念。

系统资金只能用来进行商业活动，比如开公司。

而个人财产才是真正属于自己的，可以随便花的。

"刺激！看一下详细规则。"

裴谦用意念点击光幕上的按钮。

一个新的页面展开：

【宿主必须从事正常、合理、合法、有一定技术含量的商业活动。】

【以下行为均属违规行为，请注意。】

【盈余类：】

【1.大规模购置房产、炒房。】

【2.购买数字货币、参与庞氏骗局、非法集资等违法行为。】

【3.投机倒把、倒卖物资、扰乱市场秩序。】

【……（点击展开剩余的97条违规行为）】

【亏损类：】

【1.做慈善，或将公司财产转赠他人。】

【2.以远高于市场价的标准采购、雇佣员工、租用办公地点、购买办公用品。】

【3.消极怠工，效率过于低下，长时间内未能创造任何价值。】

【……（点击展开剩余的97条违规行为）】

【补充条款：宿主不可向任何人、以任何方式透露或暗示系统本身或该挑战的存在。】

【系统对违规行为的定义拥有最终解释权。】

"规则还真严谨。"

裴谦浏览着这多达200条的违规行为，心中暗暗盘算。

原本他脑海中出现的几个"快速致富"方案，比如炒房、买币什么的，都被系统禁止了。

不过，这些也都是常规操作，系统禁止也很合理。

"最后一步了，看看这个转化比例..."

他继续点击光幕，进入下一步。

【正在随机生成盈亏转化比例……】

【请稍候...】

【生成完成！】

【盈余转化比例为100:1，亏损转化比例为1:1】

"等等，这个比例..."

裴谦仔细一看，瞬间愣住了。

亏损转换比例，1:1？

也就是说，亏1块钱，就能得到1块钱个人财产？

那把系统资金全都赔光，岂不是...

【系统资金：50000】

【个人财产：443】

【如果将系统资金全部亏损，可获得个人财产：50000元】

【总计个人财产：50443元】

"卧槽！"

裴谦差点从床上蹦起来。

"这也太爽了吧？"

"亏了钱也相当于是血赚啊！"

"随机生成了这么好的转换比例？我简直是个欧皇啊！"

"可惜就是盈余转化比例有点低，不过没关系，亏钱比赚钱容易多了！"

裴谦感觉自己运气爆棚。

正常创业成功的公司少之又少，创业失败的公司一抓一大把。

只要正常开公司、正常创造价值，然后让方向稍微跑偏一点点...

"所以，接下来要做的，就是让系统资金的50000变成0，然后让个人资产的443变成50443。"

"不就是亏钱吗？我觉得这并不难。"

裴谦自言自语，嘴角忍不住上扬。

【最后一步：请为您的公司命名（点击此处输入）】

裴谦考虑了一下，用意念在输入框中输入：

**腾达网络技术有限公司。**

寓意是"飞黄腾达"。

也就是希望腾达这个公司能够飞快地"黄"掉。

【"腾达网络技术有限公司"注册完成。】

【恭喜宿主绑定财富转换系统，祝您...呃...创业顺利？】

光幕上的文字信息消失了，回到了面板的最初始状态。

【财富转换系统】

【宿主：裴谦】

【盈余转化比100:1，亏损转化比1:1】

【下次结算时间：14天后】

【系统资金：50000】

【个人财产：443】

裴谦看着这些数字，心情复杂。

"系统啊系统，你让我亏钱，这可太为难我了..."

"毕竟，创业成功对我来说，就是最大的失败啊..."

他深吸一口气，眼中闪烁着自信的光芒。

"不过没关系。"

"不就是亏钱吗？"

"我觉得我行的！"

窗外，室友马洋的声音传来：

"谦哥！你还在床上干嘛？真的要迟到了！"

裴谦微微一笑。

"来了来了..."
