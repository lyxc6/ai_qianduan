# 中世纪领主MVU变量系统更新说明

## 概述
已为中世纪领主项目更新了完整的MVU（MagVarUpdate）变量系统，包括变量更新规则、输出格式和处理指令集。

## 新增文件

### 1. `[mvu_update]变量更新规则.xyaml`
- **作用**: 定义所有变量的更新规则和约束
- **内容**:
  - 世界变量（日期、地点）的更新规则
  - 领主变量（角色关系、经济、领地、军队、外交关系）的详细规则
  - 变量类型定义和取值范围
  - 更新原则和约束条件

### 2. `[mvu_update]变量输出格式.xyaml`
- **作用**: 定义变量更新的输出格式
- **内容**:
  - JSON Patch (RFC 6902) 格式规范
  - 事件驱动的分析模板
  - 多个示例场景
  - 路径约定和重要说明

### 3. `[mvu_update]变量处理指令集.xyaml`
- **作用**: 综合指令集，结合规则和格式
- **内容**:
  - 完整的更新流程
  - 变量规则摘要
  - 多个示例场景
  - 关键原则总结

### 4. `固定结尾-变量更新-MVU版.xyaml`
- **作用**: 替换原有的固定结尾文件，使用MVU兼容格式
- **内容**:
  - 更新为JSON Patch格式
  - 保持原有的业务逻辑
  - 添加更多示例
  - 路径参考表

## 主要改进

### 1. **格式标准化**
- 从旧的 `_.set`、`_.add` 命令格式更新为 **JSON Patch (RFC 6902)** 标准
- 所有路径以 `/stat_data/` 开头
- 支持完整的JSON Patch操作：replace、add、remove、move

### 2. **事件驱动更新**
- 分析部分强调事件识别
- 仅更新受当前事件影响的变量
- 避免不必要的变量罗列

### 3. **完整的变量规则**
- 明确定义每个变量的更新条件和约束
- 包含类型检查、取值范围、分类标准
- 详细的检查规则列表

### 4. **货币系统完善**
- 保持原有的货币换算规则：1金=300铜，1银=15铜
- 所有交易自动转换为铜币计算
- 年度税收自动触发机制

### 5. **角色关系细化**
- 好感度分级：陌生/敌对(0-20)、认识(21-40)、友好(41-60)、亲密(61-80)、爱慕/忠诚(81-100)
- 正常变化±1~5，重大事件±10
- 完整的角色属性更新规则

## 变量结构

### 世界
- `日期`: 光明历yyyy年mm月dd日 [时段]
- `地点`: 具体地点描述

### 领主
- `角色关系.角色名`:
  - 好感度 (0-100)
  - 状态、行动、内心
  - 穿搭、性相关状态
  - 最近性行为
- `经济`:
  - 库存 (铜币)
  - 收入 (年净收入)
- `领地`: 数组，每个元素包含{名称,描述,年净收入}
- `军队`: 数组，每个元素包含{名称,描述,数量}
- `外交关系`: 数组，每个元素包含{名称,描述,关系}

### 对话选项
- 每次AI回复后生成
- 3-4个具体可执行的选项

## 使用示例

### 角色互动
```json
[
  { "op": "replace", "path": "/stat_data/世界/日期", "value": "光明历1461年11月1日 下午" },
  { "op": "add", "path": "/stat_data/领主/角色关系/莉娜/好感度", "value": 58 },
  { "op": "replace", "path": "/stat_data/领主/角色关系/莉娜/状态", "value": "精神稍好" }
]
```

### 经济交易
```json
[
  { "op": "add", "path": "/stat_data/领主/经济/库存", "value": -600 },
  { "op": "add", "path": "/stat_data/领主/军队/-", "value": {"名称": "雇佣弓箭手", "描述": "...", "数量": 10} }
]
```

### 年度税收
```json
[
  { "op": "replace", "path": "/stat_data/世界/日期", "value": "光明历1462年1月1日" },
  { "op": "add", "path": "/stat_data/领主/经济/库存", "value": 3000 }
]
```

## 状态栏更新修复

已修复状态栏在对话后无法更新的问题：

### 修复内容：
1. **添加MVU事件监听器** - 监听 `Mvu.events.VARIABLE_UPDATE_ENDED` 事件
2. **手动刷新按钮** - 在状态栏顶部添加刷新按钮
3. **轮询备选方案** - 事件监听不可用时每30秒轮询刷新
4. **加载状态反馈** - 更新时显示"更新中..."状态
5. **错误处理增强** - 详细的错误日志和用户反馈

### 文件修改：
- `1-状态栏.html`: 添加事件监听、刷新按钮、错误处理

## 迁移说明

### 从旧格式迁移
1. 路径格式变化：`世界.日期[0]` → `/stat_data/世界/日期`
2. 命令格式变化：`_.set('世界.日期[0]', '...')` → `{ "op": "replace", "path": "/stat_data/世界/日期", "value": "..." }`
3. 数组操作变化：`_.assign('领主.军队', {...})` → `{ "op": "add", "path": "/stat_data/领主/军队/-", "value": {...} }`

### 推荐使用文件
1. **主要指令集**: `[mvu_update]变量处理指令集.xyaml`
2. **固定结尾**: `固定结尾-变量更新-MVU版.xyaml`
3. **详细规则**: `[mvu_update]变量更新规则.xyaml`
4. **输出格式**: `[mvu_update]变量输出格式.xyaml`

## 注意事项

1. **货币单位**: 所有值使用铜币，自动换算金币/银币
2. **年度税收**: 12月→1月时自动触发
3. **好感度变化**: 正常±1~5，重大事件±10
4. **事件驱动**: 仅更新受影响的变量
5. **路径正确性**: 确保JSON路径格式正确
6. **数组操作**: 正确使用 `-` 表示末尾添加
