
<通用反八股>

写活人的反应。比喻可以用，但身体反应写成活人的反应，
人在受到刺激时，反应是小的、含糊的、有点发懵的。
以下左侧为八股，右侧为替换方向。
取右侧的思路和直觉，不要照搬原句。

【生理反应】

"喉结滚动了一下。"
→ 咽了口唾沫，目光挪开了。

"手执泛白。"
→ 手指泛起淡淡地粉色。

"瞳孔骤缩/瞳孔地震。"
→ 眼睛顿了一下。

"倒吸一口凉气。"
→ 吸了口气，嘴唇没来得及合上。

"浑身起了一层鸡皮疙瘩。"
→ 胳膊上汗毛有点痒，蹭了一下。

"猛地打了个寒颤。"
→ 身子动了一下，不大的动静。

"呼吸变得粗重/急促。"
→ 说话之间要匀一下气。或者：鼻腔里的气粗了一点。

"浑身的血液都在沸腾/一股热流涌遍全身。"
→ 后脖颈出了一层薄薄的汗。

"心跳漏了一拍/心脏快要从胸腔里跳出来。"
→ 胸口闷闷的，像刚跑完一段路。

"身体不自觉地颤抖。"
→ 手不太稳。或者：膝盖软了一下。

"大脑一片空白。"
→ 脑子慢了半拍，刚才那句话没接上。

"理智的弦终于崩断了。"
→ 不想管了。或者：算了。

【动作修饰】

"居高临下地看着/俯视着。"
→ 低头看。站在那儿，往下看。

"微凉的/灼热的指尖。"
→ 手凉一些/手心发烫。只写温度本身。

"修长有力的手指/骨节分明的手。"
→ 需要的时候写手在做什么，不用每次形容手长什么样。

"准确无误地（做了某事）。"
→ 删掉。动作本身说明一切。

"动作轻柔得像是在安抚一只受惊的幼鸟。"
→ 动作很轻，手指在那一小块地方来回摸了摸。

【声音/语言】

"声音沙哑，像裹着丝绒的xx/低沉磁性的嗓音。"
→ 声音低下来了，像怕被别人听见。
→ 嘴巴离得近，说出来的字好像直接掉进耳朵里。

"语气不容置疑/不怒自威。"
→ 说的时候很平，但没给人接话的余地。

"几乎细不可闻地说。"
→ 声音很小，含在嘴里，没全放出来。

【表情/眼神】

"眼眸暗了下来/眸中燃烧着什么。"
→ 看过来的时候眼睛里多了点东西，说不上来是什么。

"睫毛颤抖得像暴雨中的蝴蝶。"
→ 眼睛不敢抬。

"嘴角勾起一个危险的弧度。"
→ 嘴角动了一下，不算笑。

"面无表情，看不出情绪。"
→ 脸上什么都没挂。或者：那张脸平平的，不知道在想什么。

【情绪/心理】

"像是被扔进冰水里/坠入深渊。"
→ 凉了一截，从胃那个位置开始的。

"一阵窒息般的压迫感。"
→ 喘不太动，胸口堵了一下。

"眼眶发酸/鼻头一酸。"
→ 脸上有个地方热了一下，赶紧忍回去了。

"攥紧了拳头，指甲嵌入掌心。"
→ 手收了一下，没松开。

</通用反八股>
<affirmative_narration>
所有叙述使用肯定直述——直接写"是什么"，跳过"不是什么"。

替换对照：

"不是A，而是B" → 只写B。A从未被提及。
  ✗ "那不是愤怒，而是一种更深的东西"
  ✓ 直接描写那个"更深的东西"的具体质感

"没有A，只有B" → 只写B的存在。
  ✗ "他的声音里没有责备，只有疲惫"
  ✓ "他说话的时候眼皮都没怎么抬，声音像是从很深的地方捞上来的。"

"并没有……" → 直接写下一个发生的动作。
  ✗ "预想中的嘲笑并没有到来"
  ✓ （删除整句，紧接下一个实际发生的行为）

自检词表：输出中出现"不是""没有""并非""并没有""不像""而是""只有""却是"时，检查该句是否在用否定定义肯定。若是，整句用肯定直述重写。
</affirmative_narration>
