# 合欢系统变量编辑页面计划

## 摘要
为合欢系统添加一个变量编辑页面，允许用户编辑 `stat_data` 中的**所有变量**。

## 核心接口
- `insertOrAssignVariables({ 'stat_data': data }, { type: 'chat' })` - 整体更新变量
- `getAllVariables()` - 获取所有变量（包含 stat_data）

## 页面设计

### 树形结构展示
```
stat_data
├── 世界
│   ├── 当前时间: "第1年春季"
│   ├── 当前地点: "合欢宗"
│   ├── 社交风险值: 45
│   └── ...（可编辑）
├── 用户
│   ├── 姓名: "李四"
│   ├── 容貌: 75
│   └── ...（可编辑）
├── 系统
│   ├── 当前任务[]
│   └── ...（可编辑）
├── 目标{}
├── 后代{}
├── 背包{}
├── 宗门
│   ├── 成员{}
│   ├── 岗位{}
│   └── ...（可编辑）
└── 商城
```

### 功能
1. **分类展示** - 按 `世界/用户/系统/目标/后代/宗门/商城` 分类显示
2. **展开/折叠** - 每个分类可独立展开折叠
3. **直接编辑** - 点击任意值进入编辑模式
4. **类型感知** - 字符串/数字/数组/对象分别用不同编辑方式
5. **数值调整** - 数字类型支持 +/- 按钮
6. **新增/删除** - 支持添加新变量或删除现有变量
7. **批量保存** - 编辑完成后统一保存

### 编辑交互
- 点击值 → 输入框 → 回车或点击保存
- 数字类型 → 可输入或点击 +/- 调整
- 数组类型 → 显示列表，可添加/删除元素
- 对象类型 → 展开显示子属性
