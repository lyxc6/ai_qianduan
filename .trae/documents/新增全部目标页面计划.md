# 新增"全部目标"页面计划

## 需求概述
新增一个显示 `stat_data.目标` 中所有记录的页面，与现有的"在场目标"和"关系网"页面互补。

## 当前状态分析

### 现有目标页面
| 页面 | 路由 | 筛选条件 | 用途 |
|------|------|----------|------|
| TargetPage | `/target` | 在场 + 性别匹配 | 显示当前场景中的目标 |
| NetworkPage | `/network` | 已攻略/亲密/稳定关系 | 显示已攻略的目标 |

### 缺失功能
- 没有页面显示 `stat_data.目标` 中的**全部记录**

## 修改方案

### 1. 新增页面组件：`src/合欢系统/pages/AllTargetPage.vue`

```vue
<template>
  <div>
    <div class="hh-page-header">
      <BackButton />
      <div class="hh-page-title">全部目标APP</div>
    </div>
    <div class="hh-content">
      <div class="hh-summary">
        共 {{ targets.length }} 位目标
      </div>
      <div v-if="targets.length" v-for="t in targets" :key="t.姓名" class="hh-card">
        <div class="hh-card-title">
          {{ t.姓名 }}
          <span v-if="t.是否被攻略" class="hh-tag-tag">已攻略</span>
          <span v-if="t.是否在场" class="hh-tag-green">在场</span>
        </div>
        <!-- 显示与TargetPage相同的所有详细字段 -->
      </div>
      <div v-else class="hh-empty">尚未记录任何目标</div>
    </div>
  </div>
</template>
```

### 2. 添加路由：`src/合欢系统/index.ts`

在 routes 数组中添加：
```typescript
{ path: '/alltarget', name: 'alltarget', component: () => import('./pages/AllTargetPage.vue') },
```

### 3. 添加首页入口：`src/合欢系统/pages/HomePage.vue`

在 apps 数组中添加：
```typescript
{ path: '/alltarget', ico: '全', label: '全部目标', icoClass: 'hh-alltarget' },
```

### 4. 添加图标样式

```scss
.hh-alltarget {
  background: linear-gradient(135deg, #fda4af, #f43f5e);
}
```

## 文件清单

| 操作 | 文件路径 |
|------|----------|
| 新增 | `src/合欢系统/pages/AllTargetPage.vue` |
| 修改 | `src/合欢系统/index.ts` |
| 修改 | `src/合欢系统/pages/HomePage.vue` |

## 验证步骤
1. 刷新酒馆网页
2. 在首页看到"全部目标"图标
3. 点击进入页面
4. 确认显示所有目标记录（无论是否在场、是否被攻略）
