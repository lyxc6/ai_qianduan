# 响应式适配和样式优化计划

## 一、问题分析

### 1.1 变量编辑页面响应式问题
**问题描述：**
- EditPage和VarRow组件使用了固定的 `min-width`，在小屏幕上可能导致布局溢出
- 输入框和按钮没有良好的响应式适配

**当前代码：**
```scss
.var-key {
  min-width: 5.625rem; // 90px 固定宽度
}
.var-input {
  min-width: 4rem; // 64px 固定宽度
}
```

### 1.2 主角页面信息列被压缩问题
**问题描述：**
- `.xx-info-item` 使用 `display: flex; justify-content: space-between`
- 当右侧内容很长时，左列的 `.xx-info-label` 会被压缩换行

**当前代码：**
```scss
.xx-info-item {
  display: flex;
  justify-content: space-between;
  align-items: center;
  // 缺少防止左列被压缩的设置
}
```

### 1.3 设置页面数据管理区美化
**问题描述：**
- 当前只有"编辑变量"按钮，缺少其他数据管理功能
- 按钮样式比较基础，缺少视觉层次

**当前代码：**
```vue
<div class="xx-btn-group">
  <button class="xx-btn xx-btn-primary" @click="goEdit">
    <i class="fa-solid fa-edit"></i>
    <span>编辑变量</span>
  </button>
</div>
```

## 二、解决方案

### 2.1 变量编辑页面响应式优化
1. **移除固定 `min-width`**，使用相对单位
2. **优化输入框自适应**，允许在小屏幕上换行
3. **调整按钮和行项目间距**，适配不同屏幕
4. **添加媒体查询**，针对小屏幕设备特殊处理

### 2.2 主角页面信息列布局修复
1. **添加 `flex-shrink: 0` 到 `.xx-info-label`**，防止左列被压缩
2. **使用CSS Grid替代Flexbox**，更精确控制列宽
3. **添加响应式断点**，在小屏幕上使用两行布局

### 2.3 设置页面数据管理区美化
1. **扩展数据管理功能**：
   - 刷新变量
   - 重置变量
   - 导入/导出配置（预留）
2. **美化按钮样式**：
   - 添加图标和渐变背景
   - 使用卡片式布局
   - 添加悬停效果
3. **优化分组布局**：
   - 使用网格布局
   - 添加间距和阴影

## 三、实施步骤

### 步骤1：修复main.scss中的 `.xx-info-item` 样式
```scss
.xx-info-item {
  display: flex;
  justify-content: space-between;
  align-items: flex-start; // 改为flex-start，允许内容顶部对齐
  gap: 1rem; // 添加间距
  padding: 0.625rem 0;
  border-bottom: 0.0625rem solid $xx-border;

  &:last-child {
    border-bottom: none;
  }
}

.xx-info-label {
  flex-shrink: 0; // 防止被压缩
  font-size: 0.875rem;
  color: $xx-light-cyan;
  font-weight: 500;
  min-width: 5rem; // 设置最小宽度
}

.xx-info-value {
  flex: 1; // 右列自适应
  font-size: 0.875rem;
  color: $xx-ink;
  font-weight: 600;
  text-align: right; // 右对齐
  word-break: break-word; // 允许换行
}
```

### 步骤2：优化VarRow组件响应式
```scss
.var-row {
  flex-wrap: wrap; // 允许换行
  gap: 0.5rem;
}

.var-key {
  min-width: auto; // 移除固定宽度
  flex: 0 0 auto; // 不伸缩，使用内容宽度
}

.var-value {
  flex: 1 1 auto; // 自适应
  min-width: 0; // 允许缩小到0
}
```

### 步骤3：美化SettingsPage数据管理区
```vue
<div class="xx-card settings-card">
  <div class="xx-title">数据管理</div>
  <div class="settings-grid">
    <button class="settings-btn settings-btn-primary">
      <i class="fa-solid fa-edit"></i>
      <span>编辑变量</span>
    </button>
    <button class="settings-btn settings-btn-secondary">
      <i class="fa-solid fa-rotate"></i>
      <span>刷新变量</span>
    </button>
  </div>
</div>
```

### 步骤4：添加响应式断点
```scss
@media (max-width: 375px) {
  .xx-info-item {
    flex-direction: column;
    align-items: flex-start;
    gap: 0.25rem;
  }
  
  .xx-info-value {
    text-align: left;
  }
  
  .var-row {
    flex-direction: column;
    align-items: stretch;
  }
}
```
