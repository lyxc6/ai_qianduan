# 设置页面按钮功能优化计划

## 一、需求分析

### 1.1 当前状态
设置页面（SettingsPage.vue）当前有三个按钮：
- 编辑变量：跳转到EditPage编辑stat_data中的变量
- 刷新变量：目前只是显示提示信息
- 重置变量：目前只有确认对话框

### 1.2 需求变更
1. **移除重置变量按钮**：删除该功能
2. **刷新变量功能重定义**：重新处理新的更新变量
   - 功能：重新加载/处理变量输出格式
   - 可能涉及：重新读取`变量输出格式.yaml`文件
3. **新增编辑更新变量按钮**：
   - 功能：编辑`变量输出格式.yaml`文件的内容
   - 文件路径：`e:\Work\ai小说\ai_qianduan\src\玄霄宗\世界书\变量\变量输出格式.yaml`
   - 编辑内容：第13-28行的更新变量格式模板

## 二、技术方案

### 2.1 移除重置变量按钮
直接从SettingsPage.vue中删除该按钮及相关函数

### 2.2 刷新变量功能实现
**功能定义**：重新处理新的更新变量
- 调用酒馆助手API重新加载变量
- 显示处理结果提示

**实现方式**：
```typescript
function refreshVariables() {
  // 调用酒馆助手的变量刷新功能
  const allVars = getAllVariables();
  // 重新处理更新变量
  toastr.success('变量已刷新', '成功');
}
```

### 2.3 编辑更新变量功能实现
**方案一：跳转到新的编辑页面（推荐）**
- 创建新页面 `EditUpdateFormatPage.vue`
- 专门用于编辑变量输出格式
- 提供文本编辑区域
- 保存时写入YAML文件

**方案二：弹窗编辑**
- 使用模态对话框
- 在对话框中编辑格式内容
- 适合简单编辑场景

**推荐方案一**，因为：
- 编辑内容较多（多行YAML格式）
- 需要专门的编辑界面和验证
- 与现有"编辑变量"页面风格一致
