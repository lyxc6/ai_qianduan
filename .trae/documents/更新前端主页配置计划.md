# 更新前端主页配置计划

## 一、现状分析

已完成的修改：

* 创建了合并后的 `ManagementPage.vue`（经营APP）

* 删除了原 `IndustryPage.vue` 和 `BasePage.vue`

尚未完成的修改：

1. **index.ts 路由配置**：仍然引用已删除的 `BasePage.vue` 和 `IndustryPage.vue`
2. **HomePage.vue 应用列表**：仍然显示独立的"据点"和"产业"两个APP按钮

## 二、修改方案

### 2.1 更新路由配置 (index.ts)

* 将 `/base` 和 `/industry` 路由合并为 `/management`

* 指向新创建的 `ManagementPage.vue`

### 2.2 更新主页应用列表 (HomePage.vue)

* 删除"据点"和"产业"两个独立按钮

* 添加一个"经营"按钮，指向 `/management` 路由

## 三、具体修改步骤

| 步骤 | 文件             | 修改内容                                        |
| -- | -------------- | ------------------------------------------- |
| 1  | `index.ts`     | 将 `/base` 和 `/industry` 路由替换为 `/management` |
| 2  | `HomePage.vue` | 删除"据点"和"产业"按钮，添加"经营"按钮                      |

### 步骤1：更新路由配置

```typescript
// 修改前
{ path: '/base', name: 'base', component: () => import('./pages/BasePage.vue') },
{ path: '/industry', name: 'industry', component: () => import('./pages/IndustryPage.vue') },

// 修改后
{ path: '/management', name: 'management', component: () => import('./pages/ManagementPage.vue') },
```

### 步骤2：更新主页应用列表

```typescript
// 修改前
{ path: '/base', ico: '点', label: '据点', icoClass: 'hh-base' },
{ path: '/industry', ico: '业', label: '产业', icoClass: 'hh-industry' },

// 修改后
{ path: '/management', ico: '营', label: '经营', icoClass: 'hh-management' },
```

同时需要添加 `hh-management` 的样式。

## 四、预期结果

* 路由配置从两个独立路由合并为一个 `/management` 路由

* 主页应用列表从两个独立按钮合并为一个"经营"按钮

* 用户点击"经营"按钮后进入合并后的经营APP，通过 Tab 切换查看据点和产业
