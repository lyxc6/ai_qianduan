# 前端优化计划

## 一、需求分析

用户要求：
1. 移除前端的背包页面（因为背包系统已移除）
2. 确认经营页面的变量正确
3. 修改主页按钮显示，使用 Font Awesome 图标

## 二、修改文件清单

| 文件 | 修改内容 |
|------|----------|
| 删除 BagPage.vue | 删除背包页面文件 |
| index.ts | 移除背包路由 |
| HomePage.vue | 移除背包按钮，改用 Font Awesome 图标 |
| ManagementPage.vue | 确认变量正确（如需要则修改） |

## 三、修改步骤

1. **删除背包页面**
   - 删除 BagPage.vue 文件
   - 从 index.ts 中移除背包路由

2. **修改主页按钮**
   - 修改 HomePage.vue，移除背包按钮
   - 将按钮图标从汉字改为 Font Awesome 图标
   - 使用 `<i class="fa-solid fa-xxx"></i>` 格式

3. **确认经营页面变量**
   - 检查 ManagementPage.vue 的变量引用
   - 确认资产相关变量正确
