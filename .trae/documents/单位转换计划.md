# 单位转换计划

## 一、需求概述
1. 使用 `svh` 单位尝试
2. 修改规则，禁止使用 `px`，改用其他单位

## 二、方案设计

### 2.1 单位选择策略
- 高度：使用 `svh`（小视口高度）、`vh`
- 宽度：使用 `vw`、百分比 `%`
- 字体和间距：使用 `rem`（根元素相对单位）
- 边框等小尺寸：使用 `em` 或 `rem`

### 2.2 基准设置
设置根元素字体大小为基准：
```scss
html {
  font-size: 16px; // 基准值
}
```

### 2.3 转换规则
- 16px = 1rem
- 100vh = 100svh
- 小尺寸（<8px）可用 `0.125rem` 等

## 三、具体修改内容

### 3.1 修改项目规则
更新 `project_rules.md`，添加禁止使用 `px` 的规则

### 3.2 修改样式文件
- 所有 `main.scss` 中的 `px` 转换为 `rem`
- 高度相关使用 `svh`
- 字体大小使用 `rem`

### 3.3 检查所有组件样式
检查各页面中的 scoped style 是否也有 `px` 需要转换

## 四、实施步骤
1. 更新项目规则文档
2. 修改 `main.scss` 样式单位
3. 检查并修改各组件的内联样式
4. 验证在不同视口下的显示效果

## 五、文件清单
- `.trae/rules/project_rules.md` - 添加单位规范
- `src/玄霄宗/界面/styles/main.scss` - 单位转换
