# 前端数值0显示问题修复计划

## 问题分析

在前端页面中，大量使用了 `x || '—'` 或 `x || 0` 这种短路求值方式来提供默认值。但这会导致：
- 当 `x` 的值是数字 `0` 时，会被当作 falsy 值处理，错误地显示 `'—'` 或 `0`（对于本来就用 `|| 0` 的地方还好，但如果是评分类值如 `容貌: 0`，就不会显示）
- 当 `x` 的值是布尔值 `false` 时，也会被当作 falsy 值处理

### 受影响的字段（按类型分类）
| 类型 | 示例字段 | 问题描述 |
|------|----------|----------|
| 数值评分 | 容貌、气质、身材、好感度、戒备心、忠诚度、能力值、贡献值等 | `0` 会被替换为 `'—'` |
| 数量统计 | 月收益、维护成本、容纳人数、已有效双修不同目标数等 | `0` 可能被替换为 `'—'` |
| 风险等级 | 社交风险值、曝光风险值、风险等级 | `0` 会被替换为 `'—'` |
| 年龄/等级 | 年龄、等级等 | `0` 会被替换为 `'—'` |

## 修复方案

### 方案：创建工具函数统一处理显示

在 `utils.ts` 中添加一个 `displayValue` 函数，正确处理各种类型的值：
- 数字类型：始终显示数字（包括 0）
- 布尔类型：直接显示 true/false 或根据需求转换
- 字符串类型：空字符串 `''` 或 `undefined`/`null` 显示 `'—'`
- 数组类型：保留原 `formatArray` 逻辑

### 修复步骤

1. **修改 utils.ts**
   - 添加 `displayValue` 工具函数

2. **修改所有需要修复的页面**：
   | 页面 | 需要修改的地方 |
   |------|----------------|
   | `UserPage.vue` | 容貌、气质、身材等评分，合欢值、现金等数量 |
   | `TargetPage.vue` | 容貌、气质、身材、好感度、戒备心等 |
   | `AllTargetPage.vue` | 同上 |
   | `SectPage.vue` | 宗门资金、影响力、隐蔽度、稳定度、现代化指数等 |
   | `ManagementPage.vue` | 据点/产业的等级、隐蔽度、豪华度、容纳人数、月收益、维护成本等 |
   | `MemberPage.vue` | 忠诚度、能力值、贡献值、野心、泄密风险等 |
   | `SystemPage.vue` | 校园名望、城市名望、社交风险值、曝光风险值等 |
   | `NetworkPage.vue` | 综合评分、好感度、有效双修次数等 |
   | `BagPage.vue` | 数量等 |

## 修复方法

### 1. 修改 utils.ts
```typescript
// 在现有代码基础上添加
export function displayValue(value: unknown): string {
  if (value === null || value === undefined) return '—';
  if (typeof value === 'number') return String(value);
  if (typeof value === 'boolean') return value ? '是' : '否';
  if (typeof value === 'string') return value || '—';
  return String(value);
}
```

### 2. 修改页面模板
将所有 `x || '—'` 或类似的判断替换为 `displayValue(x)`，并在 script 中导入该函数。

对于数组处理，保留原有的 `formatArray` 函数。
