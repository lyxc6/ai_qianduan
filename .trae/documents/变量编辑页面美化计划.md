# 变量编辑页面美化计划

## 一、当前问题分析

### 1.1 EditPage.vue 问题
- 页面布局简单，缺乏视觉层次感
- 返回按钮样式普通，与整体仙侠风格不符
- 待应用变更区域样式不够突出
- 缺少状态反馈和交互体验

### 1.2 VarRow.vue 问题
- 整体样式较为基础
- 编辑输入框样式不够美观
- 加减按钮和数组操作按钮样式需要优化
- 缺少悬停效果和过渡动画

## 二、设计目标

### 2.1 整体风格
- 保持水墨风修仙主题风格
- 使用柔和的色彩搭配
- 添加适当的阴影和边框效果
- 优化交互反馈

### 2.2 返回按钮设计
- 采用古风按钮样式
- 添加水墨风格边框
- 悬停时显示动画效果
- 符合整体设计语言

### 2.3 变量列表美化
- 添加卡片式布局
- 优化行间距和内边距
- 改进输入框样式
- 添加修改状态的视觉标识

## 三、实施步骤

### 3.1 修改 EditPage.vue
1. 优化页面整体布局
2. 重写返回按钮样式（古风水墨风格）
3. 美化待应用变更区域
4. 添加操作反馈动画

### 3.2 修改 VarRow.vue
1. 优化行项目样式
2. 改进输入框设计
3. 美化加减按钮
4. 添加悬停和选中效果

### 3.3 更新全局样式（main.scss）
1. 添加新的按钮样式
2. 添加变量编辑专用样式

## 四、涉及文件

## 五、设计规范

### 5.1 颜色方案
- 主色调：#4A6FA5（青灰色）
- 成功色：#059669（绿色）
- 警告色：#D97706（金色/橙色）
- 错误色：#DC2626（红色）
- 背景色：#FAFAF7（宣纸白）

### 5.2 按钮样式
- 使用渐变背景
- 添加水墨风格边框
- 悬停时显示阴影效果
- 点击时有缩放动画

### 5.3 卡片样式
- 使用圆角边框
- 添加顶部渐变装饰条
- 使用柔和的阴影效果

## 六、风险处理

1. **样式冲突**：确保新样式使用独特的类名前缀
2. **兼容性**：使用标准CSS属性，避免使用实验性特性
3. **性能**：避免过度使用复杂动画和阴影效果
4. **响应式**：使用rem单位确保在不同屏幕尺寸下正常显示

## 七、验证步骤

1. 构建项目验证样式是否正确
2. 检查页面布局是否正常
3. 测试交互功能是否正常
4. 确认返回按钮和变量编辑功能正常工作
