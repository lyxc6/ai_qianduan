# 风格设置功能实现计划

## 一、需求分析

### 1.1 需求变更
1. **移除编辑更新格式按钮**：从设置页面删除该按钮及相关路由
2. **添加风格设置功能**：提供多个CSS风格主题供用户选择

### 1.2 风格主题设计

| 主题名称 | 主题标识 | 设计风格 | 配色特点 |
|---------|---------|---------|---------|
| 水墨风修仙 | `ink-wash` | 传统水墨风格 | 淡雅灰蓝、宣纸白、墨黑 |
| 古风雅致 | `ancient-style` | 古典雅致风格 | 赭石红、金色、深木色 |
| 简约现代 | `minimal-modern` | 简洁现代风格 | 极简白、浅灰、深蓝 |
| 暗夜修仙 | `dark-cultivation` | 深色主题 | 深紫、暗金、暗夜黑 |

## 二、技术方案

### 2.1 移除编辑更新格式
1. 删除SettingsPage.vue中的编辑更新格式按钮
2. 删除EditUpdateFormatPage.vue页面
3. 从路由配置中移除相关路由

### 2.2 风格设置实现
**方案：CSS变量主题切换**
- 使用CSS变量定义各主题颜色
- 通过JavaScript动态切换主题类名
- 保存主题偏好到酒馆变量系统

### 2.3 文件结构
```
src/玄霄宗/界面/
├── styles/
│   ├── main.scss          # 主样式文件
│   └── themes/
│       ├── ink-wash.scss     # 水墨风主题
│       ├── ancient.scss      # 古风主题
│       ├── modern.scss       # 简约现代主题
│       └── dark.scss         # 暗夜主题
├── components/
│   └── ThemeSelector.vue    # 主题选择器组件
└── pages/
    └── SettingsPage.vue     # 设置页面（修改）
```
