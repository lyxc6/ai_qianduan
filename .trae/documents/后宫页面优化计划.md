# 后宫页面优化计划

## 一、需求概述

1. **后宫卡片点击进入详情页面**
2. **移除后宫管理和编辑变量文字**
3. **给详情页添加符合风格的返回按钮**
4. **固定总高度，动态分辨率适配**

## 二、设计方向（基于frontend-skill）

### Visual Thesis
水墨修仙风格，简洁克制，信息密度适中。整体呈现古籍画卷的质感，文字清晰可辨。

### Content Plan
- 主页面：时间和地点 + 后宫角色卡片列表
- 详情页：角色完整信息 + 返回按钮

### Interaction Thesis
- 点击卡片展开详情，平滑过渡
- 返回按钮简洁优雅，符合水墨风格

## 三、具体修改内容

### 3.1 创建后宫详情页 HaremDetailPage.vue
- 显示单个后宫角色的所有变量信息
- 顶部固定返回按钮（水墨风格）
- 内容区域可滚动

### 3.2 修改 HaremPage.vue
- 移除"后宫管理"和"查看后宫角色信息"文字
- 后宫卡片改为可点击
- 点击进入详情页

### 3.3 修改 index.ts 路由
- 添加后宫详情页路由 `/harem/:name`

### 3.4 修改样式
- 固定高度：`height: 100dvh`
- 响应式适配不同分辨率
- 添加详情页返回按钮样式

## 四、实现步骤

1. 创建 `pages/HaremDetailPage.vue`
2. 修改 `index.ts` 添加路由
3. 修改 `HaremPage.vue` - 移除多余文字，卡片可点击
4. 修改 `main.scss` - 固定高度，返回按钮样式
5. 更新 `App.vue` - 固定高度适配
