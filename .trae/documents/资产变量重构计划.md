# 资产变量重构计划

## 一、需求分析

用户要求将宗门的 `总资产` 字段从单个数值类型改为记录类型 `资产`，包含以下子字段：
- 名称：资产名称
- 价值：资产价值
- 所有者：资产所有者
- 来源：资产来源

## 二、修改文件清单

| 文件 | 修改内容 |
|------|----------|
| 变量结构.js | 将 `总资产` 字段改为 `资产` 记录类型 |
| 变量更新规则.yaml | 更新资产相关的更新规则 |
| 变量输出格式.yaml | 更新资产相关的检查点 |
| 初始变量文件 | 更新资产的初始值 |
| ManagementPage.vue | 更新前端展示逻辑 |

## 三、修改步骤

1. **修改变量结构.js**
   - 将 `总资产: nonNegative('宗门总资产，包含资金和产业估值')` 改为记录类型
   - 添加资产对象的子字段：名称、价值、所有者、来源

2. **修改变量更新规则.yaml**
   - 更新宗门检查规则，移除对总资产数值的检查
   - 添加资产记录的更新规则

3. **修改变量输出格式.yaml**
   - 更新宗门相关字段，将 total assets 改为 assets 记录

4. **修改初始变量文件**
   - 将 `总资产: 100000` 改为 `资产:` 对象，包含初始资产记录
   
5. **修改前端 ManagementPage.vue**
   - 更新资产页面的展示逻辑
   - 显示资产列表而不是单个数值

## 四、预期结果

- 资产字段变为记录类型，可以存储多个资产条目
- 每个资产包含名称、价值、所有者、来源信息
- 前端经营页面显示资产列表

## 五、注意事项

- 保持与现有代码的兼容性
- 确保资产记录类型符合 MVU 变量框架的要求
