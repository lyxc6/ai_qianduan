# 合欢系统前端重构计划

## 摘要
将合欢系统从原生 HTML/jQuery 实现重构为 Vue 3 + TypeScript 实现，采用独立页面切换导航，保留现有粉色手机风格同时适配 PC 端。

## 当前状态分析

### 现有实现
- **文件位置**: `src/合欢系统/index.html`
- **技术栈**: 原生 HTML + jQuery + 内联 CSS/JS
- **交互模式**: 底部应用图标网格，点击切换面板显示
- **样式风格**: 粉色渐变手机界面，带呼吸动画

### 现有功能模块
| 模块 | 功能 |
|------|------|
| 合欢系统 | 系统状态、空间、提示 |
| 主角信息 | 用户属性、评分、状态 |
| 在场目标 | 女性/男性/目标列表 |
| 关系网 | 已攻略目标列表 |
| 后代 | 子嗣信息 |
| 里程碑 | 已解锁成就 |
| 宗门 | 宗门信息、制度 |
| 成员 | 成员列表、岗位 |
| 据点 | 据点信息 |
| 产业 | 产业信息 |
| 任务栏 | 当前任务 |
| 行动建议 | 建议列表 |
| 系统商城 | 商品列表、购买 |

## 实施计划

### 步骤 1: 创建项目结构

创建以下文件结构：
```

├── index.html          # 入口文件（简化）

├── 加载和卸载.ts       # 生命周期管理
├── styles/

├── pages/              # 页面组件
│   ├── HomePage.vue    # 首页（应用网格）
│   ├── SystemPage.vue  # 合欢系统
│   ├── UserPage.vue    # 主角信息
│   ├── TargetPage.vue  # 在场目标
│   ├── NetworkPage.vue # 关系网
│   ├── ChildPage.vue   # 后代
```

### 步骤 2: 实现核心功能

#### 2.1 入口和路由
- `index.html`: 仅保留 `<div id="app"></div>`
- `router.ts`: 使用 `createMemoryHistory` 配置页面路由
- `index.ts`: 初始化 Vue 应用并挂载

#### 2.2 共享组件
- `AppHeader.vue`: 显示时间、"合欢宗OS"、电量，适配手机风格
- `BackButton.vue`: 返回按钮，点击返回首页

#### 2.3 页面组件
每个页面组件负责：
- 从 `getAllVariables()` 获取数据
- 显示对应模块信息
- 点击进入详情或执行操作

#### 2.4 响应式适配
```scss
// PC 端: 双栏布局，左侧导航 + 右侧内容
@media (min-width: 768px) {
  .phone-container {
    max-width: 100%;
    border-radius: 0;
  }
  .app-grid {
    display: grid;
    grid-template-columns: repeat(4, 1fr);
  }
}

// 手机端: 单栏，底部导航（通过页面切换实现）
@media (max-width: 767px) {
  .phone-container {
    max-width: 430px;
    border-radius: 30px;
  }
}
```

### 步骤 3: 数据获取和状态管理

保持现有数据接口：
- 使用 `getAllVariables()` 获取 `stat_data`
- 事件监听 `Mvu.events.VARIABLE_UPDATE_ENDED` 刷新数据
- 通过 Vue `provide/inject` 或 Pinia 管理共享状态

### 步骤 4: 关键交互逻辑

#### 商城购买功能
保持现有逻辑：将购买指令追加到酒馆输入框
```typescript
function handleBuy(item: string, price: string, quantity: number) {
  setSTInput(`购买商城物品：${item}\n购买数量：${quantity}...`, 'append');
}
```
