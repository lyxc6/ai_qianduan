# 宗门产业系统与据点系统合并计划

## 一、现状分析

### 两文件内容对比

| 维度       | 宗门产业系统.yaml                | 宗门据点系统.yaml               |
| -------- | -------------------------- | ------------------------- |
| **核心概念** | 产业/生意（合法外壳、资金、变现渠道）        | 据点/场所（物理位置、功能）            |
| **类型列举** | 传媒工作室、直播公会、形象管理、高端社交俱乐部等8种 | 宿舍秘密据点、校园社团、公寓工作室、私密会所等8种 |
| **主要属性** | 名称、类型、等级、负责人、月收益、维护成本等10项  | 等级、地点、类型、隐蔽度、豪华度、容纳人数等9项  |
| **主要规则** | 收益周期性结算、高端产业需资源支撑          | 据点需合法解释、升级需资源支持           |

### 存在的重复/重叠

1. **类型重叠**：

   * 形象管理工作室（产业系统和据点系统都有）

   * 直播/传媒基地（据点系统）≈ 直播/短视频公会（产业系统）

   * 私密会所（据点系统）≈ 高端社交俱乐部（产业系统）

2. **属性重叠**：负责人、风险等级、维护成本、等级

3. **概念关联**：据点是产业的物理载体，产业是据点的功能外壳

***

## 二、合并方案

将两个独立 YAML 文件合并为一个 `宗门经营系统.yaml`，统一管理"据点"和"产业"两大体系。

### 合并后文件结构

```yaml
<Modern Hehuan Sect Management System>

# 概述
- 说明两大系统的关系：据点是产业的物理载体，产业是据点的功能外壳

# 一、据点类型
（保留据点系统.yaml 的8种据点类型）

# 二、据点属性
（保留并统一属性列表）

# 三、据点建设规则
（保留据点系统.yaml 的建设规则）

# 四、产业类型
（保留产业系统.yaml 的8种产业类型）

# 五、产业属性
（保留并统一属性列表）

# 六、产业经营规则
（保留产业系统.yaml 的经营规则）

# 七、综合规则
- 据点与产业的绑定关系
- 资源统一调度
```

## 三、需要修改的文件清单

### 3.1 世界观 YAML 文件

| 操作 | 文件                         |
| -- | -------------------------- |
| 新建 | `世界观/宗门经营系统.yaml`（合并后的新文件） |
| 删除 | `世界观/宗门产业系统.yaml`          |
| 删除 | `世界观/宗门据点系统.yaml`          |

### 3.2 变量结构文件

| 文件            | 需要修改的内容                              |
| ------------- | ------------------------------------ |
| `世界观/变量结构.js` | `宗门.据点` 和 `宗门.产业` 的 Zod Schema 结构和描述 |

**当前结构**（第196-231行）：

* `宗门.据点`：名称、类型、地点、等级、隐蔽度、豪华度、容纳人数、功能、维护成本、风险等级、负责人

* `宗门.产业`：名称、类型、等级、负责人、月收益、维护成本、合法外壳强度、招募效率、资源价值、风险等级、关联据点

**合并后**：两个 Schema 结构保持独立（因为它们的属性差异较大），但相关描述和注释需要更新以反映合并后的体系。

### 3.3 前端页面文件

| 文件                       | 需要修改的内容                            |
| ------------------------ | ---------------------------------- |
| `pages/IndustryPage.vue` | 页面标题改为"经营APP"或"产业据点APP"，合并据点和产业的显示 |
| `pages/BasePage.vue`     | 可选择删除或合并到经营APP                     |

**IndustryPage.vue 当前结构**：

* 显示产业数据：名称、类型/等级、负责人、月收益/维护成本、合法外壳强度、招募/资源、风险等级、关联据点

**BasePage.vue 当前结构**：

* 显示据点数据：名称、类型/等级、地点、隐蔽/豪华、容纳、功能、维护成本、风险等级、负责人

**合并方案**：将两个页面的数据合并到一个新的 `ManagementPage.vue`（经营APP）中，同时显示据点和产业。

## 四、具体修改步骤

### 步骤1：创建合并的世界观文件

1. 创建 `世界观/宗门经营系统.yaml`
2. 整合两个文件的所有内容
3. 消除类型重复（如形象管理工作室统一表述）
4. 新增综合规则说明两者关系

### 步骤2：删除原世界关文件

1. 删除 `世界观/宗门产业系统.yaml`
2. 删除 `世界观/宗门据点系统.yaml`

### 步骤3：更新变量结构文件

1. 更新 `世界观/变量结构.js` 中 `宗门.据点` 和 `宗门.产业` 的描述注释，反映合并后的体系

### 步骤4：创建合并后的前端页面

1. 创建 `pages/ManagementPage.vue`（经营APP）

   * 合并显示据点和产业的卡片

   * 使用 Tab 或分区展示两种类型
2. 可选：保留 `pages/BasePage.vue` 作为据点专用页面

### 步骤5：删除或重构原前端页面

1. 删除 `pages/IndustryPage.vue`（合并到新页面）
2. 删除或保留 `pages/BasePage.vue`

***

## 五、预期结果

* 世界观目录从 2 个 YAML 文件合并为 1 个

* 变量结构保持 `宗门.据点` 和 `宗门.产业` 两个独立 Schema，但描述更新

* 前端从 2 个独立 APP 页面合并为 1 个经营APP（或保留为2个但内容更统一）

* 消除类型重复，明确定位

* 综合规则阐明两系统关系和交互逻辑
