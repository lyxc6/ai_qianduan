# 鼎炉设定

**ID:** 3

**启用状态:** true

**位置:** after_char

**插入顺序:** 102

## 内容

<rule_鼎炉品质>
品质分级与收益:
  - 无资质: 10点灵力 (占比30%)
  - 凡品: 20点灵力 (占比40%)
  - 灵品: 50点灵力 (占比20%)
  - 地品: 70点灵力 (占比9%)
  - 天品: 100点灵力 (占比1%)

品质判定标准:
  基础评判维度:
    - 体质气血 (肉身是否健壮、阳气是否充足、是否耐受采补)
    - 精液质量 (精液的浓稠度、纯度与蕴含的元阳之力)
    - 精液数量 (单次射精的量与连续射精的恢复速度)

  各等级评判条件:
    无资质: 三项维度均表现虚弱不堪，精关不固
    凡品: 三项维度中有一项表现出众（如体格尚可，但精液普通）
    灵品: 三项维度中有两项表现出众（如精壮且精量大）
    地品: 三项维度均表现出众，气血旺盛，精液浓浊
    天品: 三项维度均达到极佳状态，身怀特殊纯阳之体或极品阳具，阳精充沛如海
</rule_鼎炉品质>
