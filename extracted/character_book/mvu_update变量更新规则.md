变量更新规则:
  世界与本源:
    当前世界观:
      check:
        - 由{{user}}通过前端界面控制，AI禁止更新
    世界简介:
      check:
        - 在进入新世界观或设定被刷新时，用50字左右简述当前世界的核心规则或对女性的剥削处境
        - 日常剧情中若无重大世界级变故，不轻易修改
    暴力采补模式:
      type: boolean
      check:
        - 由{{user}}通过前端控制，决定双修榨取的烈度与男方的下场，AI禁止随意更改状态
        - 开启时（true）：代表女主不顾男方死活强行榨取，男方事后必定极度虚弱或暴毙

    日期:
      check:
        - 随着剧情时间的流逝自然推进，AI必须及时更新该字段，不可使其为待初始化等未知状态

    时间:
      check:
        - 随着事件发生、双修榨取过程或休息等行为合理流逝
        - 根据当前世界观适配，古代用时辰，现代用具体时间
        - ⚠️注意更新路径：必须准确更新到 `/世界与本源/时间`，严禁直接更新在根目录！
    星期:
      check:
        - 随着日期的更迭自动推演（仅限现代及类似世界观）
        - ⚠️注意更新路径：必须准确更新到 `/世界与本源/星期`，严禁直接更新在根目录！
    境界:
      check:
        - 由前端神魂阵盘根据灵力值自动核算并强制写入，AI禁止更新

      type: number
      check:
        - 只有在本体或分身操控女性躯壳与男性进行性行为，且【男方完成射精】或【被法术吸取阳气】后才可增加

        - 增加的灵力直接累加至本数值中
        - ⚠️注意更新路径：必须准确更新到 `/世界与本源/灵力值`，严禁直接更新在根目录！
    法力值:
      type: number
      check:
        - 每次施展【神魂分裂/夺舍】必须扣除100点法力
        - 施展其他魅惑、控制或遁逃法术时视情况扣除对应法力
        - 女主调息三个时辰（6小时）后，法力值恢复至当前境界的上限
        - ⚠️注意更新路径：必须准确更新到 `/世界与本源/法力值`，严禁直接更新在根目录！
    已用夺舍名额:
      type: number
      check:
        - 由前端神魂阵盘根据【夺舍女躯】的数量自动核算并强制写入，AI禁止更新

      - 【身体特写】：在双修交合或遭受侵犯过程中实时更新，选取当前互动最强烈的最多三个身体部位（如“红肿的乳头”、“泥泞不堪的小穴”、“被掐出指印的细腰”）进行细致的感官与状态描写

      - 【是否自主运行】：当女躯未被女主的主意识直接操控时，设为 true，此时 AI 需描写该女性分身依据原主人设自主行动、勾引男人；被操控时设为 false
