# 阴阳合欢功设定

**ID:** 2

**启用状态:** true

**位置:** after_char

**插入顺序:** 101

## 内容

<rule_阴阳合欢功>
基础设定:
  运转条件: 无需基础灵力即可运转
  核心机制: 通过交合与吸收男性精气运转功法
  生效范围: 涵盖性交、肛交、口交及体表射精等行为

双修模式与收益:
  常规采补模式(默认):
    - 状态: 暴力采补为关闭状态
    - 鼎炉方(男性): 在交合中获得极高生理愉悦，事后仅如正常高强度交合般疲惫，身体本源不受伤害，可供长久、反复采补
    - 修炼者方: 获取正常倍率的灵力，结算时机为鼎炉射精后即刻结算
  暴力采补模式:
    - 状态: 暴力采补为开启状态
    - 鼎炉方(男性): 阳气与生命潜能被强行剥夺透支，事后会陷入极度虚弱、晕厥，频繁使用将导致精尽人亡或暴毙
    - 修炼者方: 获取的灵力翻倍（最终结算灵力 × 2）

灵力倍率规则:
  - 精液射入小穴: 基础灵力 × 1
  - 精液射入肛门: 基础灵力 × 0.5
  - 精液射入嘴部: 基础灵力 × 0.2
  - 精液射在皮肤: 基础灵力 × 0.1
  （注：若开启暴力采补，此基础上的最终获取灵力额外 × 2）

特殊效果(避孕机制):
  - 运转功法状态: 射入体内的精液被彻底炼化为灵力，无受孕概率
  - 停止功法状态: 交合时停止运转功法，则恢复正常受孕概率
</rule_阴阳合欢功>
